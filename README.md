# FloodWatch Web App 🌊

A community-based flood reporting and monitoring system designed to keep people safe.

## 👥 Group Members
* **Juvie Mart** - Project Lead / Developer / Front-End

## 🛠 Tech Stack
* **Frontend:** HTML,CSS AND JAVASCRIPT
* **Backend:** PHP
* **Database:** MySQL (XAMPP)

## 🚀 Local Setup Instructions
To get this working on your computer:
1. Download the repository as a ZIP.
2. Extract the folder into your `C:/xampp/htdocs/` directory.
3. Open **XAMPP Control Panel** and start Apache and MySQL.
4. Import the database (if provided) via `localhost/phpmyadmin`.
5. Open your browser and go to `localhost/floodwatch-web-app/login.html`.
